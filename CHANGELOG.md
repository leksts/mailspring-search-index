# Changelog

## 1.0.0

First release.

- Search Index preferences tab showing, per account, how many messages are not yet searchable and an estimate of the temporary disk space.
- Index All Mail requests the text of all older messages in batches, newest first, so the sync engine adds them to the search index.
- Pause and resume, and continuing after a restart.
- Longer waits and bigger batches for accounts that are slow to respond.
- A log of every run in `search-index.log`.
- English and Dutch interface text.
